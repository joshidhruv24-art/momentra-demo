# Momentra website preview

Static demo website for Momentra, built as a single-page HTML prototype.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `momentra-demo`.
2. Upload `index.html` and this `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. GitHub Pages will show the public website address, normally `https://<your-github-username>.github.io/momentra-demo/`.

## What this demo does

- Shows a studio dashboard, sample events, gallery, upload controls, processing progress, and guest mobile preview.
- Allows local file selection only to demonstrate the upload interaction. Selected files are not transmitted or stored.
- Uses sample gallery images from Unsplash and sample studio/event data.

## Not connected yet

Real studio accounts, cloud storage, RAW decoding, natural color-processing workers, QR creation, face detection/matching, guest downloads, billing, and account security need a backend. Do not use this static demo to collect real wedding photographs or selfies.
